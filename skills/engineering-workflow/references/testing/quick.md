# Quick Testing

Use for a small number of direct checks with clear criteria and environment.

## Workflow

1. Restate the criterion and expected signal.
2. Confirm prerequisites and target.
3. Run the narrowest authoritative existing check.
4. Confirm the intended cases executed.
5. Interpret exit status, assertions, and relevant output.
6. Report PASS, FAIL, or BLOCKED with the command and decisive evidence.

Create no testing artifacts. Reclassify to STRUCTURED if the checks need a designed matrix, new test
architecture, or durable coordination. Do not broaden the direct check without a risk-based reason.
